# 📚 Book Store Front-End Project

A simple, responsive front-end web application that allows users to browse books, add them to a shopping cart, and complete a purchase. The project includes user authentication (login/signup), order form collection, and auto-generated receipts.

## 🚀 Features

- 🔐 **User Authentication** – Login for existing users and Signup for new users
- 🛒 **Add to Cart** – Browse books and add selected items to the shopping cart
- 📝 **Order Form** – Collects user details:
  - Home Address
  - Contact Number
  - Email Address
- 🧾 **Auto-Generated Receipt** – After order submission, a receipt is generated showing:
  - Purchased books
  - User information

## 🛠️ Technologies Used

- **HTML5** – Structure of the web pages
- **CSS3** – Styling and responsive design
- **JavaScript** – DOM manipulation, cart logic, form handling, and receipt generation

## 🔧 How to Run the Project

1. Clone the repository or download the ZIP file
2. Open `index.html` in any modern web browser
3. Sign up as a new user or log in with existing credentials
4. Browse books, add to cart, and complete the purchase
